OTC048 AUTOMATION - USER GUIDE

AUTOMATIC UPDATES
When enabled by your publisher, OTC48 checks GitHub for updates once a day when
you open it. Choose menu option 9 to check immediately. You can continue using
the installed version when offline or choose to postpone an update.
Public GitHub updates need no GitHub account or sign-in. Your saved JDE login is
used only for JDE. If your publisher chooses private GitHub hosting instead,
GitHub sign-in and repository access are required for those private updates.
Accept an update to install it into the existing folder. After success, exit and
open the desktop shortcut again. Excel workbooks, JDE login, settings, and reports
are kept. No uninstall is needed. Updates never start during an automation run.
If update setup fails, the installer restores the previous application files.
Users on an older version without updating support need the new EXE once.

INSTALL AND FIRST SETUP
1. Keep OTC48.exe anywhere and double-click it.
   Only this EXE needs to be shared; the application and Excel templates are inside.
2. Choose an installation folder in the setup window. Browse or type the path.
   The suggested folder is %LOCALAPPDATA%\Programs\OTC048, or your existing app.
   Choose an empty folder or the existing OTC048 application folder.
   Setup tests create/write/read/delete access before installing anything.
   If access is denied, select another folder. Setup does not change permissions
   or request administrator access.
3. Setup checks for compatible Node.js, packages, and Chromium browsers already
   available. It reuses matching files and installs only missing requirements.
   Internet may be needed for missing dependencies. Wait for setup to finish.
   A desktop icon is created after successful dependency validation. Setup shows
   Installation complete. Press Enter to exit; setup does not open automation.
4. Open the OTC048 Automation desktop icon. Enter the JDE URL if not supplied.
5. Enter your JDE user ID and masked password once. Your Windows account protects
   the saved password and the application reuses it for later runs.
No development tools or manual Node.js/npm installation are required.
The terminal shows a 48 banner, colored status messages, download progress,
and an activity indicator while packages are prepared. Detailed tool output
is saved in the Logs folder instead of filling the screen.
Use 64-bit Windows 10/11. Allow about 2 GB of free space for setup and reports.
If setup is interrupted, reopen the setup EXE to finish the missing parts.
JDE access requires your company network/VPN and the right JDE permissions.
Keep OTC48.exe for updates and application repair.
If a desktop icon could not be created, use OTC048.cmd in the installed folder,
or reopen setup. Menu option 8 can recreate the icon.
If startup fails, share the application log path printed on screen with
your support team. Company security restrictions may require IT approval.

YOUR EXCEL FILE
The working workbook is created at:
  Documents\OTC048 Automation\Input\OTC048.xlsx
It initially contains the current demo data. Update its values for your run.
Documents may be redirected to OneDrive or a company-managed location.
OTC048-Demo.xlsx keeps a separate copy of the example data.
OTC048-Template.xlsx has the same sheets and headings with blank input rows.

LATER RUNS
Open the OTC048 Automation desktop icon. Dependencies are checked quietly on
every launch. If something is missing, choose Y at the Install/repair prompt
to restore it, or N to exit without starting automation. After a repair, the
checks run again. A healthy launch does not reinstall or download anything.
1. Choose option 3 to open your saved Excel file.
2. Update the data, then save and close the workbook.
3. Choose option 1 to run using that file.
4. Confirm the TestNo and browser mode. Your previous choices are remembered.
5. Check the displayed details and confirm the run.
The saved JDE login is reused; you do not enter it for each run.
Use option 2 to select a different .xlsx file. That selection is remembered.
Both browser modes run the same workflow: visible browser plus console messages,
or console messages only with the browser hidden.
The console may ask for business values that are not provided in Excel.

MENU
1. Run using my saved Excel file.
2. Select another Excel file and run.
3. Open my Excel file to update data.
4. Open the blank Excel template.
5. Open results and logs.
6. Change the JDE URL and set up the login for that environment.
7. Update my JDE user ID or password.
8. Recreate desktop shortcut.
0. Exit.

EXCEL RULES
Keep the Header, Detail_Line, and Other sheet names and column headings intact.
The TestNo: value must match across all three sheets. Each test needs one Header
row, one Other row, and at least one Detail_Line row.
Use MM/DD/YYYY dates or actual Excel dates, and plain values rather than formulas.
The launcher checks Excel before opening JDE.
Demo data also creates and updates real transactions. Use an approved JDE test
URL and suitable workbook data.

RESULTS
Each run has its own folder under Documents\OTC048 Automation\Runs.
run.log records business progress; report\index.html contains the HTML report.
If a run fails, check the report and what JDE saved before starting again.
The application never retries the entire workflow automatically.
Successful report submission does not prove a background job has finished.

LOGIN AND SETTINGS
Use option 7 when your JDE password changes. If the saved login cannot be read,
the application requests setup again. A different JDE URL needs its own login
setup. Do not copy a saved login file to another user or PC.
The saved password uses Windows protection and is not stored in .env or JSON.
Settings and credentials are under %LOCALAPPDATA%\OTC048 Automation.
Keep workbooks and reports private because they contain business data.
Browser traces are disabled. Only one launcher runs per Windows account.

UPDATE AND UNINSTALL
Close OTC048 and open the new setup EXE. Select the existing app folder, or
another empty writable folder, and click Install. Your workbooks, saved login,
settings, and reports are preserved. Compatible dependencies are reused, and
missing requirements are installed only when necessary. Setup recreates the icon.
If setup fails, application files are rolled back and you can reopen setup to
retry. Diagnostic logs are in %LOCALAPPDATA%\OTC048 Automation\Logs.
Uninstall through Windows Installed apps. Your saved JDE login is removed;
your Excel files, settings, cached downloads, and reports are kept.
